# GK Xcode Themes

A set of custom Xcode color themes, each available in **Light** and **Dark**.
They share the `GK ` prefix so they group together in Xcode's theme list
(Settings → Themes), with each Light/Dark pair sitting next to each other.

## Themes

* **GK Amoyly** (Light / Dark) — colorful, Monokai-flavored palette
* **GK Batman** (Light / Dark) — muted, cool palette
* **GK Default** (Light / Dark) — vibrant, balanced palette
* **GK Glacier** (Light / Dark) — cool blue + warm accents, uses [Fira Code](https://github.com/tonsky/FiraCode)

## Installation

* Download the repo.
* Run `install.sh` or copy the `.xccolortheme` files into
  `~/Library/Developer/Xcode/UserData/FontAndColorThemes/`.

The Glacier themes require the [Fira Code](https://github.com/tonsky/FiraCode) font to be installed.
